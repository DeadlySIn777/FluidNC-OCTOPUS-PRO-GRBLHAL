# External vendor reference documents

Vendor PDFs, photographs and manual extractions are not redistributed in this public source export. The corrected wiring documents retain their historical reference filenames/hashes for provenance; those names do not indicate bundled files here.

- [STEPPERONLINE CL57T V4.1 manual](https://www.omc-stepperonline.com/download/CL57T-V41_user_manual.pdf). Reviewed copy: 14 pages, Revision 4.1, May 2023; SHA-256 `3eec9304c770ff68a5ccbd68f105789edfb35f5c91a9977531a30756a918d7da`.
- [BIGTREETECH Octopus Pro official hardware repository](https://github.com/bigtreetech/BIGTREETECH-OCTOPUS-Pro). Select the actual v1.1 board drawing and schematic; hashes of the originally reviewed files are retained in `../RESEARCH.md`.

An online file can change. Match its revision and content before using it, and match every physical board/drive/connector to the actual installation. Source documentation never substitutes for physical acceptance.
