USB-ONLY FLASH SEQUENCE

POWER CHANGES HAPPEN ONLY WITH USB DISCONNECTED

  1. 01
    PROVE THE BOARD IDENTITY

    Photograph OCTOPUS PRO V1.1, STM32F429ZGT6, and the board underside. Stop if any marking differs.

  2. 02
    MAKE IT A BARE BOARD

    Use a dry nonconductive bench. Physically remove MAIN, MOTOR, BED, every driver/adapter, every I/O plug, and USB. No 24V, 36V, 5V field supply, spindle, relay, motor, probe, or machine cable remains.

  3. 03
    FIT ONLY THE MCU POWER JUMPER

    Place one jumper exactly inside BTT's red rectangle above. Leave BOOT0 alone.

  4. 04
    PREPARE THE MICROSD

    Format it FAT32, place the downloaded candidate at the card root as exactly firmware.bin, and make sure Windows did not create firmware.bin.bin.

  5. 05
    INSERT CARD / CONNECT USB-C

    Insert the card, then connect one known data-capable USB-C cable to the PC. Do not press BOOT0 and do not run a DFU utility. Let the bootloader finish before disconnecting USB.

  6. 06
    UNPLUG USB / VERIFY THE CARD

    Remove USB first, then remove the card and inspect it on the PC. Success requires FIRMWARE.CUR. If firmware.bin remains, stop and correct the card, filename, or board identity.

  7. 07
    VERIFY IDENTITY BEFORE DEFAULTS

    With the card removed and USB-power jumper still fitted, reconnect USB. Save $I+ and $$. Only after the MR-1 F429 identity matches, issue $RST=* once in the sender, reconnect, and require the read-only controller preflight to pass.

  8. 08
    REMOVE THE TEMPORARY JUMPER

    Archive the preflight report, disconnect USB, then remove the MCU USB-power jumper before any future 24V MAIN connection or machine wiring.

USB DOES ENERGIZE MCU / 5V + 3.3V LOGIC / STATUS LEDS TREAT THE BOARD AS LOW-VOLTAGE LIVE WHILE USB IS CONNECTED.
USB DOES NOT POWER CL57T / MOTORS / SPINDLE / RELAYS / FIELD DEVICES THEY ARE PHYSICALLY ABSENT FOR THIS PROCEDURE.

DFU is a recovery method only. BTT warns that DFU can overwrite the stock bootloader; our normal image expects that 32 KiB bootloader and starts at 0x08008000.
